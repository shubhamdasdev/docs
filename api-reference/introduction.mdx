# API Reference

Welcome to the Cortex API reference documentation. This section provides detailed information about the available API endpoints, request/response formats, and authentication methods.

## Base URL

When running locally, the base URL for all API endpoints is:

```
http://localhost:8000
```

## Authentication

Authentication details and methods will be documented here.

## Response Format

The API typically returns responses in JSON format. Here's an example response structure:

```json
{
  "reasoning": [
    {
      "query": "example_query",
      "properties": "example_properties",
      "context": "example_context"
    },
    {
      "query": "another_query",
      "properties": "another_properties",
      "context": "another_context"
    }
  ],
  "final_answer": "example_final_answer"
}
```

## API Documentation Tools

Cortex API provides two interactive documentation interfaces:

1. **Swagger UI** ([/docs](http://localhost:8000/docs))
   - Interactive API testing
   - Request/response examples
   - OpenAPI specification

2. **ReDoc** ([/redoc](http://localhost:8000/redoc))
   - Clean, organized documentation
   - Easy-to-read format
   - Search functionality
